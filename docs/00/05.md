## Expand Data Collection and Analysis – Detailed Guide

Collecting rich data from your simulation is essential for understanding emergent patterns, testing hypotheses, and communicating results. Mesa’s `DataCollector` is the primary tool, but you can go far beyond basic population counts. Below are detailed ways to expand data collection and analysis in your rabbit‑grass model.

---

### 1. **Track More Model‑Level Variables**

Currently you collect only the rabbit population. Add:

- **Grass coverage**: number or fraction of cells with grown grass.
- **Total energy in the system**: sum of rabbit energy plus grass energy (if you assign an energy value to each grown grass cell).
- **Extinction flag**: whether rabbits have gone extinct (useful for batch runs).
- **Average rabbit energy**: mean energy of all rabbits.
- **Energy variance**: to see if inequality grows.
- **Births and deaths per step**: to compute vital rates.

```python
self.datacollector = mesa.DataCollector(
    model_reporters={
        "Rabbit Population": lambda m: m.agents_by_type[Rabbit].__len__(),
        "Grass Coverage": lambda m: sum(1 for a in m.agents_by_type[Grass] if a.grown) / (m.width * m.height),
        "Mean Rabbit Energy": lambda m: np.mean([r.energy for r in m.agents_by_type[Rabbit]]) if m.agents_by_type[Rabbit] else 0,
        "Total Energy": lambda m: sum(r.energy for r in m.agents_by_type[Rabbit]) + 
                                   sum(5 for a in m.agents_by_type[Grass] if a.grown),  # example: each grass gives 5 energy
    }
)
```

---

### 2. **Track Agent‑Level Variables Over Time**

Agent‑level reporters let you follow each individual’s traits. This is powerful for studying evolution and behavior.

- **Genetic traits**: `gene_speed`, `gene_metabolism` for each rabbit.
- **Energy history**.
- **Position** (to later reconstruct trajectories).

You can collect agent‑level data by passing a list of agent reporters:

```python
self.datacollector = mesa.DataCollector(
    agent_reporters={
        "Energy": "energy",
        "SpeedGene": "gene_speed",
        "MetabolismGene": "gene_metabolism",
        "x": lambda a: a.pos[0],
        "y": lambda a: a.pos[1],
    }
)
```

*Note: Collecting agent data every step can create large datasets. Consider sampling every N steps or only at key events.*

---

### 3. **Record Event Logs**

For detailed process tracing, log births, deaths, and eating events. You can store them in a list within the model or write to a file.

```python
class EcosystemModel(mesa.Model):
    def __init__(...):
        self.event_log = []  # list of (step, event_type, details)

    def log_event(self, event_type, agent=None, details=""):
        self.event_log.append((self.steps, event_type, str(agent), details))
```

Then in `Rabbit.step()`:

```python
if self.energy <= 0:
    self.model.log_event("death", self, f"energy={self.energy}")
    self.remove()
```

After the simulation, you can analyze event logs to compute lifespans, reproduction rates, etc.

### 4. **Spatial Pattern Analysis**

Rabbits may cluster or spread out. Use spatial statistics:

- **Nearest neighbor distances**: average distance to closest rabbit (indicates clustering).
- **Clark‑Evans aggregation index**.
- **Ripley's K function** (more advanced).

You can compute these after each step or at intervals using `scipy.spatial` or `pointpats`.

```python
from scipy.spatial import KDTree

def compute_nearest_neighbor(model):
    positions = [a.pos for a in model.agents_by_type[Rabbit]]
    if len(positions) < 2:
        return None
    tree = KDTree(positions)
    distances, _ = tree.query(positions, k=2)  # k=2 gives self+nearest neighbor
    return distances[:, 1].mean()  # mean distance to nearest neighbor
```

Add this as a model reporter.

### 5. **Genetic Diversity Metrics**

Track how genetic traits evolve:

- **Mean and variance** of each gene.
- **Histograms** of gene values (export for plotting).
- **Heritability** (parent‑offspring correlation) if you record parent IDs.

```python
def gene_variance(model, gene):
    values = [getattr(r, gene) for r in model.agents_by_type[Rabbit]]
    return np.var(values) if values else 0
```

### 6. **Batch Running and Parameter Sweeps**

Use `mesa.batch_run` to explore how parameters affect outcomes. Collect a summary statistic (e.g., final population, time to extinction, mean gene value) for each combination.

```python
from mesa import batch_run

params = {
    "initial_rabbits": [2, 5, 10],
    "grass_regrowth_time": [3, 5, 10],
    "reproduction_threshold": [15, 20, 25],
}
results = batch_run(
    EcosystemModel,
    parameters=params,
    iterations=5,
    max_steps=200,
    data_collection_period=1,  # collect every step? or just final?
    display_progress=True,
)
# results is a list of dictionaries, one per step per run.
```

You can then convert to a pandas DataFrame and analyze:

```python
import pandas as pd
df = pd.DataFrame(results)
# e.g., mean final rabbit population for each parameter combo
final = df[df.step == 199].groupby(["initial_rabbits","grass_regrowth_time"])["Rabbit Population"].mean()
```

### 7. **Export Data for External Analysis**

Mesa’s `DataCollector` can write directly to CSV:

```python
self.datacollector.get_model_vars_dataframe().to_csv("model_data.csv")
self.datacollector.get_agent_vars_dataframe().to_csv("agent_data.csv")
```

For large simulations, consider saving in chunks or using HDF5.

### 8. **Visualization of Results**

Beyond Mesa’s built‑in visualizers, create publication‑quality plots with matplotlib/seaborn:

- **Time series** of populations, energy, genes.
- **Distribution plots** of genes at different times.
- **Heatmaps** of rabbit density over space.
- **Animation** of agent positions (using `matplotlib.animation`).

You can also use Mesa’s `JupyterViz` for interactive exploration (if using Jupyter).

---

### 9. **Statistical Tests**

Apply statistics to your data:

- **Test for significant evolution** of genes (t‑test comparing early vs. late generations).
- **Correlation** between grass regrowth time and final population.
- **Survival analysis** (Cox regression) on rabbit lifespans.

Use libraries like `statsmodels`, `lifelines`, or `scipy.stats`.

---

### 10. **Real‑Time Dashboards**

If you run simulations interactively, create a live dashboard with:

- Plots updating each step.
- Histograms of genes.
- A map showing rabbit positions and grass state.

Mesa’s `ModularVisualization` can integrate custom JavaScript elements, but a simpler approach is to use `matplotlib` in interactive mode (`plt.ion()`).

---

### Implementation Tips

- **DataCollector overhead**: If collecting many agent reporters every step, performance may degrade. Use `sample_interval` or collect only at final step.
- **Store only what you need**: For large batch runs, consider summarizing data on‑the‑fly (e.g., only record when population changes).
- **Use numpy/pandas** for efficient calculations inside reporters.
- **Document your data**: Keep a description of variables and units.

By expanding data collection and analysis, you transform your simulation from a simple demo into a powerful tool for scientific inquiry.
