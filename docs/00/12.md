## Detailed Implementation of Energy Flow and Nutrient Cycling

Your current model already includes a basic energy flow: grass converts "energy" (sunlight implicitly) into biomass that rabbits consume. However, energy and nutrients are not recycled—dead rabbits simply vanish, and grass regrows independently of any soil nutrient pool. Adding a nutrient cycle makes the model more realistic and can lead to richer dynamics, such as soil depletion, carry-over effects from carcasses, and long-term sustainability.

Below I outline the key components you can add, how they interact, and provide code examples to integrate them into your Mesa model.

---

### 1. Core Concepts

- **Energy Flow**: Energy enters the system via photosynthesis (grass growth). It moves from grass to rabbits when they eat, and from rabbits to decomposers when they die. At each transfer, some energy is lost as heat (metabolism). Ultimately, energy leaves the system as heat.
- **Nutrient Cycling**: Nutrients (e.g., nitrogen, phosphorus) are finite and recycled. Plants absorb nutrients from the soil. When plants or animals die, decomposers break down their remains, returning nutrients to the soil.

In your model, you can represent this by:

- **Soil Nutrient Pool**: A variable per cell representing available nutrients.
- **Dead Organic Matter (Litter)**: When grass is eaten or rabbits die, instead of disappearing, they leave behind dead biomass that accumulates.
- **Decomposer Agents**: Microbes or fungi that break down litter and release nutrients back into the soil.
- **Nutrient‑Dependent Grass Growth**: Grass regrowth depends on both time and soil nutrients.

### 2. Modifications to the Model

#### a. Soil Nutrient Pool per Cell

Add a `nutrients` attribute to each grid cell (or to the grass agent). Since Mesa’s grid cells are not agents, you can store nutrient levels in a separate array or attach them to the grass agent. I recommend adding a `nutrients` dictionary or using a `Grid` of nutrient values.

```python
# In EcosystemModel.__init__
self.nutrients = {}  # or use a numpy array
for x in range(width):
    for y in range(height):
        self.nutrients[(x, y)] = 1.0  # initial nutrient level
```

Alternatively, attach nutrients to the Grass agent:

```python
class Grass(mesa.Agent):
    def __init__(self, model):
        super().__init__(model)
        self.grown = True
        self.countdown = 0
        self.nutrients = 1.0   # soil fertility at this cell
```

#### b. Dead Organic Matter (Litter)

Create a new agent class `Litter` that represents dead plant material or rabbit corpses. It could have a `biomass` or `nutrient_content` attribute that decomposes over time.

```python
class Litter(mesa.Agent):
    def __init__(self, model, nutrient_content):
        super().__init__(model)
        self.nutrient_content = nutrient_content  # nutrients to be released
        self.decomposition_rate = 0.1  # fraction released per step
```

When grass is eaten or a rabbit dies, instead of simply removing the agent, you place a Litter agent at that cell (or add to existing litter). For simplicity, you can allow only one litter pile per cell, accumulating biomass.

#### c. Decomposer Agents (optional but realistic)

You could add `Decomposer` agents (fungi, bacteria) that actively break down litter. They would have their own energy dynamics and reproduction. However, a simpler approach is to let litter decompose passively each step, releasing nutrients directly into the soil.

**Passive decomposition** (no explicit decomposer agents):

```python
# In Litter.step()
self.nutrient_content *= (1 - self.decomposition_rate)
released = self.nutrient_content * self.decomposition_rate
# Add released nutrients to the cell's soil
cell_nutrients = self.model.nutrients[self.pos]
self.model.nutrients[self.pos] += released
if self.nutrient_content <= 0.01:
    self.remove()
```

#### d. Nutrient‑Dependent Grass Growth

Modify the Grass `step` method so that regrowth depends on available nutrients. For example:

```python
def step(self):
    if not self.grown:
        self.countdown -= 1
        if self.countdown <= 0:
            # Check nutrients before regrowing
            nutrients = self.model.nutrients[self.pos]
            if nutrients >= 1.0:   # threshold
                self.grown = True
                self.model.nutrients[self.pos] -= 1.0  # consume nutrients
            else:
                # Not enough nutrients, reset countdown or wait
                self.countdown = self.model.grass_regrowth_time
```

You could make the nutrient consumption proportional to the energy gained (e.g., each grass regrowth consumes 0.5 nutrients). This creates a feedback loop: grass consumes nutrients, rabbits eat grass, dead rabbits return nutrients via litter.

#### e. Rabbit Death and Litter Production

When a rabbit dies (energy <= 0), instead of just `remove()`, you should convert its body into litter. The rabbit’s remaining energy can represent its biomass, which contains nutrients. You might assume a conversion factor from energy to nutrients.

```python
# In Rabbit.step(), after energy check
if self.energy <= 0:
    # Convert to litter
    nutrient_content = self.energy * 0.1  # conversion factor
    # Check if there is already litter at this cell
    litter_here = [a for a in self.model.grid.get_cell_list_contents([self.pos]) if isinstance(a, Litter)]
    if litter_here:
        litter_here[0].nutrient_content += nutrient_content
    else:
        new_litter = Litter(self.model, nutrient_content)
        self.model.grid.place_agent(new_litter, self.pos)
    self.remove()
```

Similarly, when grass is eaten, you might leave behind a small amount of litter (e.g., roots, inedible parts). In `get_eaten()`, you could also create litter:

```python
def get_eaten(self):
    if self.grown:
        self.grown = False
        self.countdown = self.model.grass_regrowth_time
        # Leave behind some litter (e.g., 10% of nutrient content)
        litter_nutrients = self.model.nutrients[self.pos] * 0.1
        # reduce soil nutrients slightly? or just transfer to litter
        # For simplicity, create litter
        litter_here = [a for a in self.model.grid.get_cell_list_contents([self.pos]) if isinstance(a, Litter)]
        if litter_here:
            litter_here[0].nutrient_content += litter_nutrients
        else:
            new_litter = Litter(self.model, litter_nutrients)
            self.model.grid.place_agent(new_litter, self.pos)
        return True
    return False
```

#### f. Adjust Grass Initialization

Initially, you might want all cells to have a certain nutrient level, and grass starts grown. You can set initial nutrients high enough to support several regrowth cycles.

### 3. Updated Step Order

With nutrient cycling, the step order becomes more important. A reasonable sequence:

1. **Decompose litter** – release nutrients into soil.
2. **Grass regrows** – consumes nutrients and becomes edible.
3. **Rabbits act** – move, eat grass, reproduce, possibly die (and turn into litter).
4. **Collect data** – measure soil nutrients, litter biomass, etc.

You can implement this by using separate agent lists or by calling different methods in order:

```python
def step(self):
    # Step 1: Litter decomposition
    for litter in self.agents_by_type[Litter]:
        litter.step()  # releases nutrients

    # Step 2: Grass regrowth
    for grass in self.agents_by_type[Grass]:
        grass.step()   # now depends on nutrients

    # Step 3: Rabbits act (shuffled)
    self.agents_by_type[Rabbit].shuffle_do("step")

    # Data collection
    self.datacollector.collect(self)
```

### 4. Data Collection for Nutrient Cycling

Extend your `DataCollector` to track nutrient-related variables:

- Average soil nutrients per cell
- Total litter nutrient content
- Decomposition rate
- Number of grass cells that are currently grown (now also depends on nutrients)

```python
self.datacollector = mesa.DataCollector(
    model_reporters={
        "Rabbit Population": lambda m: m.agents_by_type[Rabbit].__len__(),
        "Average Soil Nutrients": lambda m: sum(m.nutrients.values()) / (m.width * m.height),
        "Total Litter Nutrients": lambda m: sum(a.nutrient_content for a in m.agents_by_type[Litter]),
    }
)
```

### 5. Potential Extensions

- **Heterogeneous Soil**: Start with different nutrient levels per cell (e.g., using a Perlin noise map).
- **Diffusion of Nutrients**: Nutrients can slowly diffuse between neighboring cells, simulating soil processes.
- **Decomposer Population Dynamics**: If you add explicit decomposer agents, they can compete for litter and have their own life cycles.
- **Seasonal Nutrient Pulses**: In autumn, leaves fall, adding a burst of litter. You could trigger a global litter addition event periodically.
- **Microbial Loop**: Add a simple model of microbial biomass that immobilizes and mineralizes nutrients.

---

### 6. Challenges and Considerations

- **Nutrient Conservation**: Ensure that the total nutrients in the system (soil + litter + living biomass) remain roughly constant (ignoring imports/exports). Check for leaks (e.g., when agents are removed without converting to litter).
- **Stability**: Nutrient cycling can lead to oscillations or crashes. You may need to tune parameters (decomposition rate, nutrient consumption per regrowth) to avoid extinction of grass or rabbits.
- **Performance**: Storing nutrients per cell and iterating over litter agents is fine for moderate grid sizes. For large grids, consider using numpy arrays for soil nutrients and updating them in bulk.

---

### Summary

By implementing energy flow and nutrient cycling, you transform your model from a simple predator‑prey system into a more realistic ecosystem where matter is conserved and recycled. The key additions are:

- A **soil nutrient pool** per cell.
- **Litter agents** that represent dead organic matter.
- **Nutrient‑dependent grass regrowth**.
- Conversion of dead rabbits and eaten grass into litter.
- Passive or active decomposition releasing nutrients back to the soil.

These changes will create feedback loops, such as nutrient depletion followed by recovery after die‑offs, and can lead to emergent behaviors like long‑term population cycles or spatial patterns. You can then experiment with different nutrient cycling rates and observe their effects on ecosystem stability.
